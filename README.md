# COVID-19 Data Analysis and Interactive Dashboard

## Project Overview
This project analyzes COVID-19 data from 187 countries using Python. It explores confirmed cases, deaths, recoveries and active cases through data analysis and interactive visualizations.

## Dataset
- **Source:** Kaggle – Corona Virus Report
- **Records:** 49,068
- **Countries:** 187
- **Period:** January 22, 2020 to July 27, 2020

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Work Completed
- Dataset loading and inspection
- Data cleaning and date conversion
- Calculation of new cases and deaths
- 7-day rolling averages
- Case fatality rate and doubling time analysis
- Country-wise COVID-19 comparison
- Data visualizations
- Interactive dashboard creation

## Key Findings
- The United States recorded the highest confirmed cases.
- Brazil ranked second and India ranked third.
- The United States recorded the highest deaths among the top 10 countries.
- Worldwide daily cases increased during the study period.

## Project Files
- `COVID_19_Data_Analysis.ipynb` – Analysis notebook
- `COVID_19_Cleaned_Data.csv` – Processed dataset
- `COVID_19_Interactive_Dashboard.html` – Interactive dashboard
- `COVID_19_Project_Summary.pdf` – Project summary

## Note
This analysis uses historical data ending on July 27, 2020. Vaccination data is not included in the selected dataset.
